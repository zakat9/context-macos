# The 0.10.3 popover, kept for the before numbers

These four files are the installed 0.10.3 build's popover page and the rules it was built from
(`work-index.zip` 0.10.0 + the 0.10.3 patch, then `node dev/build-popover.js`). They are not part of the app.
The cycles and the screenshot scripts run the same tasks on this page and on the current one, at the same size.
