Upgrading from Context 0.12.2? Quit Context.app, install contexta.app, then open the new app once before removing the old one. Keep ~/WorkIndex/ in place to retain your tags and settings. Your existing shortcut stays the same. The app bundle ID, Chrome extension ID and helper ID have not changed.

If you use Insert context, opening contexta once updates the existing Chrome helper registration. Reload the extension in Chrome. If the helper still stops, open Settings → Insert context in contexta, turn it off and set it up again. Do not reopen the old app: it can point the helper back to itself.

Using files from a synced folder

In Finder, select a file that Google Drive, Dropbox, OneDrive, Box or iCloud Drive has stored on your Mac. This includes folders under ~/Library/CloudStorage/. contexta reads supported local formats without signing in to the service. Citations show the service and folder instead of the account folder.

Online-only files can be tagged by name and date, but contexta does not read their contents or download them. To include the text, make the file available offline in Finder first. For a Google Docs link, export and tag a supported local copy instead. Cloud handling was tested with fictional paths, not with a real cloud folder or online-only file.

Install and start

  1. Check About This Mac → Chip for an Apple M-series chip. Unzip the download, move contexta.app to Applications and open it. contexta.app has a teal tag icon. Once it opens, look for the usual tag symbol in the menu bar, not the Dock.
  2. Open a sample note. From the tag icon, choose App access → Notes → Request selected and review the macOS prompt.
  3. Tag the note, look up its tag, then copy. No browser extension or AI account is needed to try this workflow.

Help & privacy

macOS blocked the app. What should I do?

This prerelease is ad-hoc signed, not Apple-notarized. If you don’t trust the download, do not open it. You can compare the SHA-256 checksums and build the versioned source instead. Do not disable Gatekeeper.

Why is a note or file missing?

Open the supported app, select one saved item and check App access. Review System Settings → Privacy & Security → Automation if access was denied. PDF and Word files can be tagged but their body text is not read.

Can I insert directly into ChatGPT?

Copy and paste is the simplest route. The optional Chrome extension inserts at the caret and never sends; it has been tested on a fixture, not the live ChatGPT editor. See the setup guide.

Where are my tags? How do I uninstall?

The local index for contexta is in ~/WorkIndex/. Original notes, mail and files aren’t edited. To uninstall, first turn off Insert context in Settings if enabled, remove its Chrome extension, quit the app, then delete contexta.app. Keep the index if you want to retain your tags.

Report an issue with your macOS version, contexta version and steps using a fictional file. Please don’t attach personal notes or mail.
